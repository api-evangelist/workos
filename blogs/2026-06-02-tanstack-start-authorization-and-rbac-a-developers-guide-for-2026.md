This guide distinguishes between authentication and authorization in TanStack Start applications, explaining that route guards alone cannot protect server functions. It covers implementing role-based access control through middleware, organization-scoped permissions, and resource-level checks, while also introducing WorkOS RBAC as a managed solution for enterprise B2B applications requiring advanced features like identity provider integration and audit logging.
